下载链接的写法

上面的下载按钮指向本仓库的 /releases/latest 页面，也就是 GitHub 认定的最新正式版。 页面的附件文件名里内嵌版本号（如 Kanitsu-Setup-0.3.1-x64.exe），因此本页不写死任何具体版本的直链—— 那样会在下个版本发布后立即失效。

同理，SHA256SUMS.txt 也在同一位置，与安装包来自同一次构建，可用于校验下载损坏或非预期替换。

产品能力

以下均为已实现并可在桌面端使用的能力。

导入即复制副本，源目录不动

选择源文件夹后，应用把图片复制进自己的图包库。之后的浏览、整理、重命名与删除只作用于这份副本， 源目录不会被改动——这是产品的第一条约束，不是可选项。

整理前先预览分组

命名规则整理走「解析 → 预览 → 确认 → 落盘」四步，确认前不移动任何文件，落盘后可一键撤销。

三种布局的大库滚动

网格、按原比例、列表三种图片布局，统一按行虚拟化：只挂载可视窗口，万级图片的目录也能保持滚动流畅。

沉浸式查看器

缩放、平移、旋转、胶片条与键盘导航，鼠标侧键也能翻页；缩略图与原图叠层替换，加载过程不改变页面位置。

隐私预览遮挡

对敏感图片开启模糊遮挡，网格、封面与查看器三处同步生效，取消遮挡才显示内容。

查看拍摄信息

查看器内可直接调出 EXIF 摘要，无需外部工具即可确认拍摄时间、机型与曝光参数。

ZIP 导出

流式导出保留目录结构，并附带 index.json 元数据；导出过程有进度，可随时取消。

任务中心

导入、整理、导出与批量操作统一收敛到一处，进行中可取消，完成后可用 Snackbar 撤销或打开结果。

拖入文件夹导入

把文件夹直接拖进窗口即可导入，由主进程完成原生确认后才授权该目录，不会静默取得额外访问权限。

核心原则

这些约束写在设计文档里，也体现在实现的选择上。

01

副本隔离

导入后不修改源文件夹，应用只管理自己的图库。删除、重命名与整理都发生在副本上。

02

离线可用

默认不上传图片，不依赖在线服务。没有账号体系，也没有遥测上报。

03

目录即图包

每个目录都是可浏览、可整理、可导出、可设置封面的相册节点，不需要先建库再导入。

04

大库可用

缩略图、虚拟化、预取与缓存是基础能力，不是后期补丁。优先级分五级，可见内容永远优先。

格式支持

基础格式全平台一致；RAW 与 HEIF 仅在桌面端与 Android 端收录。

全平台基础格式

  • JPG
  • JPEG
  • PNG
  • WebP
  • AVIF
  • BMP
  • GIF

GIF 在网格中按设置显示动态或静态首帧。

桌面 + Android 额外收录

  • CR2
  • CR3
  • NEF
  • NRW
  • ARW
  • DNG
  • RAF
  • ORF
  • RW2
  • PEF
  • SRW
  • HEIC
  • HEIF
  • HIF

RAW 缩略图取相机内嵌预览，查看器做完整解码；HEIF/HEIC 在桌面由 libheif 解码，Android 端缩略图原生解码、全图经原生派生。

暂不支持

  • TIFF
  • 在线同步

未来的同步能力将通过独立 provider 接入，不会侵入本地库的核心流程。

安装与校验

两种形态都无需管理员权限即可安装或运行。

Setup（NSIS 安装向导）

  1. 从 Release 附件下载 Kanitsu-Setup-<version>-x64.exe。
  2. 运行安装向导，可选择安装目录；默认按用户安装，不需要管理员权限。
  3. 桌面快捷方式是可选项，开始菜单快捷方式始终创建。

推荐形态：启动速度明显快于 Portable。

Portable（免安装单 EXE）

  1. 从 Release 附件下载 Kanitsu-Portable-<version>-x64.exe。
  2. 直接双击运行，无需安装。

它是自解压程序，每次启动都要把运行时解压到 %TEMP% 再启动，因此明显慢于 Setup。

校验 SHA-256

  1. 在同一 Release 下载 SHA256SUMS.txt。
  2. 在 PowerShell 中比对哈希：
$exe = '.\Kanitsu-Setup-0.3.1-x64.exe'
$expected = ((Get-Content -Raw '.\SHA256SUMS.txt') -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $exe -Algorithm SHA256).Hash
if ($actual -ne $expected.ToUpper()) { throw "SHA-256 mismatch" }

校验文件与安装包来自同一次构建。

⚠

产物不做代码签名。这是既定的发布策略，不是待补齐的能力。EXE 的 Authenticode 状态为 NotSigned，Windows SmartScreen 首次运行可能提示风险，需要通过「更多信息 → 仍要运行」放行。 建议只从本页指向的官方 Release 下载，并核对 SHA-256。

关于数据目录

Portable 的「免安装」指单 EXE、无需安装，不表示数据随 EXE 携带。数据保存在用户首次启动时选定的数据目录里 （图库在其 albums 子目录，缩略图缓存在图库的 .kanitsu-cache 子目录）， 不会随 EXE 移动。系统应用数据目录只保留一个小的 settings.json。

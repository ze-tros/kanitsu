与现版本的主要差异

  • 01去掉「图库 / 工具」底栏与会变成「选择 / 整理 / 导出」的第二套底栏；导入改为可收缩 FAB，设置与任务进顶栏。
  • 02图包页用封面做页头，整理 / 导出 / 选择 / 封面四个动作一行排开；子目录改横向卡片带，把纵向空间留给图片。
  • 03图片网格保留卡片风格（圆角 + 细描边，间距随列数收紧），双指捏合（演示中 Ctrl+滚轮）切换 2–6 列；排序、布局、文件名、含子目录收进一个「显示」面板。
  • 04长按即多选并支持拖动连选；浮动操作栏新增 设为封面 / 模糊 / 导出。
  • 05导入、整理、导出统一进「任务中心」：顶栏进度环 + 底部进度胶囊，完成后 Snackbar 提供撤销。
  • 06查看器底部改为胶片条 + 动作栏；上滑呼出 EXIF 面板（长图纵向滚动优先），RAW 升级提示为非阻塞胶囊。
  • 07新增「继续浏览」：本地记录每个图包的上次位置，不上传。

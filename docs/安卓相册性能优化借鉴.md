> 目标：像主流安卓相册那样——载图快速、同屏预览数千张、自由滑动不卡顿、点击秒开查看。
> 本文档盘点本项目（全能看图王 / Kanitu）现状与该目标的差距，列出可借鉴的实现手段与落地路线。

## 2. 已落地的做法

### 2.1 网格虚拟化（P2）——最大收益 ✅
- 卡片尺寸固定（aspect-[4/3]、定宽列、定高 figcaption），行高可精确度量；
- 做法：网格内放一个**隐藏的同构探测卡片**，用 offsetHeight 度量真实卡片高度
  （含 figcaption 与边框），行高 = 卡高 + gap，杜绝累积漂移；
- 滚动时按 scrollTop 计算可视行区间，只挂载可视区 ± 3 行（OVERSCAN_ROWS），
  行容器绝对定位到 top: row*rowHeight，外层容器显式 height 撑起完整滚动高度；
- 一次渲染的 DOM 从 5000 降到几十个；滚动时只替换窗口内的行；
- 列数按容器宽度复算 minmax(180px, 1fr)（MIN_CARD_WIDTH=180、GRID_GAP=16）；
- 窗口缩放 / 侧栏调宽用 ResizeObserver 触发重新度量；
- **文件夹区同样虚拟化**（目录多时的卡顿源）：子文件夹卡片与图片共用同一套
  窗口机制（各自独立探测卡、分别度量），DOM 从"目录数"降到"可视行 ± 3 行"；
- **滚动重渲按窗口变化门控**：小幅滚动（仍在本行）不再 setState 整树重渲；
- **侧栏目录树 React.memo**：目录越多收益越大，每帧滚动跳过整棵树 Reconciliation；
- **滚轮平滑（类手机信息流，零依赖）**：smoothScroll.ts 接管滚轮事件，rAF 指数缓动
  逼近目标位置——滚轮离散档位变成一条连续动线，不再"跳两次"；帧率无关
  （dt 归一化），尊重 prefers-reduced-motion 回退原生滚动；
- 涉及文件：packages/ui/src/`LibraryBrowser.tsx`（文件夹/图片两个 section）。

### 2.2 共享 IntersectionObserver（P1）✅
- 新建 packages/ui/src/`visibleObserver.ts`：模块级**一个 IO 单例**（rootMargin 300px），
  所有卡片 observe/unobserve 同一个观察器，回调按 Element 分发；
- BlobImage 的懒加载改用它，替代`每卡片一个 IO`；
- 结合虚拟化：只有窗口内的卡片会被挂载，观察器数量与回调成本都降到最低。

### 2.3 滚动方向预取（P3）✅
- 主进程优先级队列从 4 级扩为 **5 级**：
  0 可见 > 1 滚动方向预取 > 2 当前目录 > 3 子文件夹/封面 > 4 全库预热
  （apps/desktop/electron/`main.ts`，`THUMB_PRIORITIES = 5`）；
- 渲染端 `thumbnailCache.ts` 导出 THUMB_PRIORITY_* 常量；滚动（rAF 节流）时
  按方向把`下一屏`缩略图以优先级 1 排入 worker（recheck: true），
  抢在整目录预热（优先级 2）之前生成；同一区间去重、快速变向时取消上一批；
- `**关键防线（修复"等待很久滚动仍重新载图"）**`：缓存合并会让可见请求复用
  预取的慢 Promise（等于排到数千张 FIFO 队尾）。thumbnailCache 对可见请求（优先 0）
  与方向预取（优先 1）做请求升级：重新发高优 IPC 并替换缓存 Promise，200ms 节流
  防抖；预取那条稍后完成时结果幂等、不重复计数；
- `**回看不再重载**`：升级/预取是同一文件的重复请求，可能乱序完成。语义约定：
  已出图的条目任何失败都不删除（慢请求晚失败不能毁掉先到的好结果）；成功结果
  在条目已被清掉时自动重建缓存——保证"加载过 → 向上回看"直接命中、不再闪加载条；
- 整目录预取并发 2 → 4（与主进程 worker 数对齐），5000 张等待时间减半；
- 与磁盘缓存叠加后，快速滚动时白格明显减少；与安卓 RecyclerView prefetch 同思路。

### 2.4 object URL 小池（P4）✅
- 新建 packages/ui/src/`objectUrlPool.ts`：引用计数 + LRU 空闲池（MAX_IDLE=64）；
- 同一 Blob 永远复用同一个 URL（WeakMap 去重）；卸载只`交还`URL 不撤销；
- 只淘汰 refs===0 的空闲条目，正在 <img> 上展示的 URL 绝不会破图；
- 回到旧目录时 URL 直接复用，创建/撤销抖动消失；
- 调试统计：getObjectUrlPoolStats()（总条目 / 空闲 / 字节）。

### 2.5 已就位、无需再动
- 多线程解码（4 worker）、可见优先调度、两级 LRU、磁盘持久化缓存、查看器渐进显示、滚动位置记忆（rAF 节流）。

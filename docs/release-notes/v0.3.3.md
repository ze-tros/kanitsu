# v0.3.3 发布说明

本版是一次集中式稳定性收敛：两轮代码审查共修复 70 余项缺陷（整理判重、导出、缩略图缓存、目录安全、列表滚动等），外加图库导航的两处新能力与 EXIF 面板、标题栏的多处体验修复。

## 新功能与体验改进

- **侧栏图包树支持一键展开/收起**：右键菜单新增「全部展开 / 全部收起」，一次作用于自身与全部子目录；再次点击已展开的图包行也可直接收起子树。侧栏条目不再随滚动条出现而被挤压。
- **子图包带可展开为网格**：「子图包」区块新增「展开为网格 / 收起为横向卡片」切换，展开后以图包网格一次看完全部子图包，不再依赖卡片带行末入口；子图包较少时也不再渲染多余的占位卡片。
- **产品主页上线**：GitHub Pages 产品主页发布，介绍下载渠道与核心能力。

## 修复

- **整理与移动更可靠**：判重纳入目录名并统一 Unicode 规范化，目标重名时正确提示而不是静默覆盖；移动拒绝覆盖已存在文件；撤销不再凭空重建已被删除的目录；整理后自动回收本次新建且为空的目录。
- **导出更稳**：ZIP 导出支持超过 65535 个条目、单文件 4GiB 的大图库（ZIP64）；导出取消判定更准确；Android 端导出失败时清理半截文件，`index.json` 保证写出。
- **缩略图与缓存**：缩略图落盘改为原子写入，缓存清理不再漏删；缩略图线程崩溃后槽位必定重建，不再出现持续空白；RAW/HEIF 解码反复失败的照片自动进入黑名单，不再拖慢整库浏览；超大 GIF 动画超时回退为静态展示。
- **隐私相关**：隐私预览切换即时生效；隐私标记现在跟随文件迁移——重命名、移动、整理、合并、撤销后模糊状态不再丢失；EXIF「全部标签」不再显示结构偏移与二进制块（MakerNote、缩略图偏移等内部数据）。
- **列表与查看器**：列表虚拟化窗口收敛，万级图库滚动更省内存；删除照片后查看器按实际结果跳转并给出失败原因；修复切换图包后卡片失去悬浮与点击的问题。
- **目录安全**：读写路径接入 realpath 解析，symlink 指向库外的目录会被跳过，杜绝目录穿越。
- **桌面端视觉**：窗口控制键（最小化 / 最大化 / 关闭）改用系统原生字形并统一 32px 控件标准，进出看图时不再有细微抖动；图库页消除临界窗口高度下的幻影滚动条。

## 已知问题 / 兼容性说明

- 图库指纹算法在本版优化为整树摘要：覆盖安装后**首次启动会对图库做一次重新扫描**（自动完成，缩略图缓存继续可用），属一次性开销。
- Android 端本轮改动较多且未经真机完整回归，正式 Release 渠道仍在准备；测试构建请继续从 GitHub Actions 获取。
- 无其他索引或缓存格式变更。Windows 产物仍为未签名分发，首次运行如遇 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

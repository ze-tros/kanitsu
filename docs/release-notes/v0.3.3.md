# v0.3.3 发布说明

本次发布聚焦桌面端标题栏与图库页面的两处视觉/交互修复，无数据格式变更，升级后索引与缩略图缓存继续可用。

## 修复

- **窗口控制键（最小化 / 最大化 / 关闭）改用系统原生字形**：三个键此前各自为政（图标库混排 + 手绘线框），字重偏细且互不一致；现改用 Windows 系统标题栏同款字形（Segoe Fluent Icons，Windows 10 自动回退 Segoe MDL2 Assets），笔画粗细与系统标准一致，颜色仍随主题与查看器深色画布自动适配。
- **窗口键几何统一**：窗口键尺寸与标题栏其他控件（导航图标、任务、导入）统一为 32px 高；主界面、查看器顶栏、图片信息面板三处顶栏内容盒等高，进出看图时窗口键不再有细微的抖动/发虚。
- **图库 / 图包页消除幻影滚动条**：内容不满一屏时，页面在临界窗口高度下会因卡片区域的固定底部留白多出几像素而出现一条几乎占满全轨道的滚动条；现在卡片区域占地贴合实际内容，不满一屏时不再出现滚动条，超出时照常滚动。多选操作时浮动操作条仍会自动避让，不遮挡最后一行。

## 已知问题 / 兼容性说明

- 无索引或缓存格式变更，覆盖安装后首次启动即可继续使用原有图库。
- Windows 产物仍为未签名分发，首次运行如遇 SmartScreen 提示，选择「更多信息 → 仍要运行」即可（详见发布策略）。

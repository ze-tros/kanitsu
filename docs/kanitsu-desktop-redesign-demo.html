DESKTOP REDESIGN

内容铺满窗口，
操作就在手边。

桌面端和 Android 端用同一套视觉 token（炭黑 / 暖纸 + 珊瑚强调色），也延续同样的「内容优先」原则；布局、控件密度和输入方式则按键鼠重新定义。页面组件仍各自独立，不与移动端共享。

与现版本的主要差异

  1. 01标题栏只留导航、全局搜索（Ctrl K 命令面板）、任务中心与导入；主题切换移入设置和命令面板。
  2. 02侧栏分成「图库」（全部 / 最近导入 / 已固定）和带封面缩略的目录树；底部显示图库占用。
  3. 03首页新增「继续浏览」和封面卡片（叠层暗示图包），支持筛选、排序、封面 / 列表两种视图。
  4. 04图包页用封面做页头，智能整理 / 导出 / 封面 / 隐私预览一行排开；子图包改为横向卡片带；吸顶工具栏滚动后显示图包名。
  5. 05图片区有网格、按原比例（自适应行高）、列表三种布局；缩略图尺寸放到状态栏滑块，也可 Ctrl+滚轮调节；排序、含子目录、文件名都在同一条工具栏上。
  6. 06多选：勾选框、Ctrl / Shift 点击、空白处框选、Ctrl+A；选中后点击改为增减选择。多选操作只在底部浮动栏出现一次，检查器只负责展示信息。
  7. 07检查器按上下文切换：图包总览（格式分布、可整理提示）、单图（EXIF 四格摘要 + 明细）、多选汇总。
  8. 08导入、整理、导出统一进任务中心：标题栏进度环 + 状态栏进度；完成后 Snackbar 提供撤销 / 打开；导入报告可展开，不再弹表格。
  9. 09智能整理拆成「选规则（显示命中数与示例映射）→ 预览分组（可改名）→ 确认」，确认前不移动任何文件。
  10. 10查看器改为沉浸式：工具栏和胶片条闲置后自动隐藏，信息面板停靠在右侧并挤开画布；RAW 显影 / 直出切换，完整解码进度用非阻塞提示展示。
  11. 11支持把文件夹拖进窗口导入；设置改为带侧栏的整页，分成外观 / 图库与数据 / 查看器 / 整理规则 / 缓存 / 诊断 / 快捷键。
